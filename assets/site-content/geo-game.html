Overview

I made Geo Game while learning how to manage shared state between JavaScript clients, and while getting used to Tailwind CSS. It became a mobile-friendly multiplayer geography game using Firebase. It works, although some bugs remain.

The source code is available [a href="https://github.com/adrianvla/geo-game"]here[/a].
