Intelligent Subtitles

July 2024. Before mLearn, I built Intelligent Subtitles, an interactive subtitle-learning extension for ASBplayer. It connected to Anki through a local Python server and analyzed Japanese subtitle text, showing word information, furigana, and dictionary lookups.

It could blur or recolor words based on whether I knew them, adjust an Anki ease threshold, and create flashcards from unfamiliar vocabulary. Later, I developed a separate application, mLearn, from the same language-learning problem.
