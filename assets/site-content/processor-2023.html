First processor

2023. Seven Verilog revisions of a 32-bit CPU, followed by a Python assembler and a C++ emulator with enough debugging windows to keep me occupied for quite a while.

Hardware

The processor had 16 general-purpose registers, an ALU, instruction decoder, register and flag memory, address logic and load/store operations. I experimented with interrupts and context restoration in the Verilog implementation. You can still see the attempts in the testbench and the successive version directories.

The emulator

The interrupt logic kept giving me trouble, and the instruction set needed a rethink. I moved to the tooling instead. The C++ emulator used SDL2 and ImGui: registers, memory, run/step controls, an instruction viewer, a simulated display and controls for interrupt behavior. I also made a Python assembler.

Some of that work taught me more than patching the old CPU would have. When it came time to propose my Travail de maturité, I designed a [direct_a href="/project?HS-Diploma-Project"]processor again[/direct_a], this time as a 64-bit system, using what I had learned from studying more different architectures and taking a different approach this time. I don't remember putting the 2023 version on a physical FPGA; the surviving Verilog testbench documents simulation work.
