Overview

This is the 2025 version of morisinc.net. The [a href="https://m2022.morisinc.net"]2022 site[/a] was an experiment in huge typography and transitions. I liked it, but it had responsiveness problems, and fragile dependencies. I wanted to try a different approach.

The current site is more like a little system: a dense project navigator, movable and animated interface elements, multiple themes, and pages assembled from simple content files. It should be possible to wander around and find something unexpected without fighting a conventional portfolio grid.

Try the color switcher in the top-right corner. The site also has its share of unnecessary moving parts. I happen to like those.

How it works

  • Projects and routes are described in JSON; pages are authored as HTML content files.
  • Custom navigation, animations, neon text, and theme changes
  • Content components for galleries, videos, and document readers
  • Multiple languages and responsive layouts

It's built with JavaScript, jQuery, Webpack, Barba.js, GSAP, Lenis, and Matter.js, among other libraries. The source code is [a href="https://github.com/adrianvla/morisinc-2025"]on GitHub[/a].

Design

I opted for a retrofuturist bento-box industrial-inspired layout with pastel colors to make it feel like a small object you could tinker with.

Recognition

The site received Best UI Design, Best Innovation, and Special Kudos at the [a href="https://www.cssdesignawards.com/sites/adrian-vlasov-portfolio/50043/"]CSS Design Awards[/a] in August 2026.

Fun facts

First, I went for a brutalist design, spent 3 weeks on it, then scratched everything because I didn't like the design I made. Then rebuilt everything from scratch, spent about a week on the design itself and finalized the code from start to finish in 1.5 weeks, totaling 2.5 weeks of development.

Why did I wait 1 year to publish it to CSSDA? Because I didn't believe that it would receive something, but it actually did.
