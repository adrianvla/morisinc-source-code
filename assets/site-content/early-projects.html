Early projects

Before I had GitHub repositories, I had piles of little programs and devices. Some of them survived in old backups; others survive mostly in my memory.

Arduino — age 5–6

My first programs included a one-dimensional shooter on a small 2-line text display. At each tick, the bullet exists, moves right 1 character. One button advanced the player to the right, when at the end of the screen it does a wrap-around. Each tick there's a small probability for a monster to spawn on the very right of the screen, when it touches the bullet it disappears and increases the score, if it touches the player, game over.

Kodu Game Lab

I made games and experiments with objects controlled by small state machines. I was curious about how behavior changes when simple agents begin interacting. Those games are the earliest ancestor I can remember of my interest in artificial emotions and simulated societies.

Sony MESH -- grade 4

A dance/workout game using Sony MESH accelerometer blocks. I compared simple patterns of movement and awarded points. It was surprisingly usable for something built from little wireless sensor toys.

STM32 -- grades 5–6

I experimented with an STM32 mini-OS/demo and wrote a small graphics library with double buffering. I was using the Arm Mbed browser IDE, running on my Windows XP DELL laptop. The drawing code also ran on an M5Stack and a separate STM32 board.
