Présentation

IoT Home Automation était un système Raspberry Pi permettant de commander des appareils personnalisés depuis un téléphone ou un navigateur. L’interface organisait les appareils par pièce et proposait des commandes propres à chaque utilisateur.

Les appareils étaient définis en JSON et le code du projet permettait de relier les commandes à du matériel GPIO ou I²C. Le système a ensuite été retiré.

Le code source est disponible sur [a href="https://github.com/adrianvla/IoT"]GitHub[/a].
