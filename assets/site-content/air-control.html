Air Control

Grades 9–10. Move your mouse off the edge of one Windows display and have the pointer arrive on a different Windows computer. I wanted separate machines to feel like one desktop, kinda like Apple Continuity worked for moving your cursor across Macs.

The code uses Win32 input handling, Winsock and UDP to exchange cursor movement over the local network. There was no video stream to decode: the pointer itself crossed between computers.

You may find the source code [a href="https://github.com/adrianvla/Air-Control"]here[/a]. Screenshots have not survived me switching computers 42 times and reinstalling windows 89 times.

I've since moved on to other projects, but I still like the idea of interfaces that make multiple systems feel continuous.
