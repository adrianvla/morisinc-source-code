Overview

I built this Raspberry Pi system to control things around the house from a phone. The dashboard grouped devices by room and let me change switches, brightness, and colors.

Device definitions were configured in JSON, with project code intended to connect controls to GPIO or I²C hardware. I eventually retired it because walking over to a light switch was easier than reaching for my phone.

The source code is available [a href="https://github.com/adrianvla/IoT"]on GitHub[/a].
