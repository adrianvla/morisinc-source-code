8BIT.js

I wrote 8BIT.js to make sprite-based Canvas games without rebuilding the same drawing and animation code every time.

This was made as an introductory library into JavaScript for [a href="https://scratch.mit.edu"]Scratch[/a] users.

It uses sprite sheets and supports scrolling backgrounds, parallax, and particle effects. The drawing API includes small calls such as put() and stamp(). The physics part wasn't finished, but the fundamental Scratch-like paradigm is.
