Learn Online

Grades 9–10. I wanted to replace [a href="https://cortex.eduge.ch/"]Cortex[/a], the school-learning platform we used in grades 9-11 at the time in Geneva. The result was a complete web application with courses, class permissions, vocabulary activities and its own interface. I showed it to some teachers. The school didn't adopt it (of course), but it was one of the biggest things I'd built up to that point.

The application

I wrote the frontend without an established UI framework, including a very small JavaScript framework of my own (not something big, but just enough abstraction to make everything work). Firebase Realtime Database handled the data. Teachers and students had different permissions; courses and classes could be organized into groups, with editable curricula and different study activities. I added gamification, a leaderboard and bulk vocabulary import through OCR. Handwritten-exam OCR remained unfinished (because the OCR at that time I used was really slow and had a really high error rate, so it remained an experiment).

I spent a lot of time on the interface: sliding panels, transitions and screens that felt like an actual application. Some of the typography was licensed from Pangram Pangram for personal use and experimentation. I didn't design the fonts.

Recovering it

I still have the source code. The frontend launches, but the original database is gone, so it fails when it tries to load real data. Nevertheless, I have managed to give it mock data.
