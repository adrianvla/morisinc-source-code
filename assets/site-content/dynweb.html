DynWeb

A small website content loader from the days when I was trying to avoid rewriting HTML whenever somebody wanted to change a page. It can load content by the URL hash, with an optional template around it.

Content can be prepared in LibreOffice or Word, exported as HTML, and put into the site's content directory. The [a href="https://github.com/adrianvla/DynWeb"]source[/a] is public.

[img src="/assets/img/dynweb.webp"]DynWeb example[/img]

Using it

Put pages such as home.html in a folder named a next to dynweb.js. Add an element with id="content" to the main page. A link to #home loads a/home.html into that element.

I used versions of this approach on [a href="https://meteor-m.com"]meteor-m.com[/a] and [a href="https://keke.morisinc.net"]the Minecraft site[/a]. The first had additional search and tagging logic. License: MIT.
